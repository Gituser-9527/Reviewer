# 内部 Alpha 反馈模板

```text
测试日期：
测试人员（角色或别名）：
浏览器版本：
扩展版本 / main commit：
API commit：
页面类型：静态 / SPA / 不支持
页面 URL 的脱敏描述（域名 + 页面类型 + 脱敏岗位标识，不记录 query 值）：
操作步骤：
预期结果：
实际结果：
Decision / Risk 是否合理：
Finding 是否准确：
Evidence 是否可定位：
误报 / 漏报 / 无法提取 / 旧岗位结果：
日志或截图的安全位置：
严重级别：low / medium / high / critical
```

不要附带 Token、Cookie、Authorization、数据库连接串、完整候选人信息、完整内部岗位页面或未脱敏截图。截图必须遮蔽个人信息、内部域名敏感参数和 Token；不得截取开发者工具中的 Authorization。
