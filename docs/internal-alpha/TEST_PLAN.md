# 内部 Alpha 测试计划

## 启动门禁

main CI 全绿；API 可访问；PostgreSQL migration 完成；测试 tenant 和受控开发凭据已由维护人员准备；扩展可重复构建并至少完成一次安装验证；至少一名试用人员完成静态页面审核和 SPA 切换；反馈渠道已明确。

## 场景记录

每项记录前置条件、操作、预期、禁止结果、实际结果、通过/失败和脱敏证据。

| 场景 | 操作 | 预期 / 禁止结果 |
| --- | --- | --- |
| 静态、JSON-LD、DOM fallback | 分别提取允许的样本页面 | 可预览并人工修正；不可上传完整 HTML |
| API 与持久化 | 提交审核并由维护人员核对 AuditRun | 真实 YAML 规则和 tenant 持久化生效；不得自动审核 |
| Finding | 手动高亮、清除 | 只标记证据，清除后恢复；不得自动高亮 |
| SPA | pushState、replaceState、popstate、hashchange | 页面变化后旧结果 `STALE`，需重新提取 |
| 同 URL 内容替换 / 暂不可提取 | 替换岗位核心内容或暂时移除内容 | 旧结果安全失效，不能继续提交或高亮 |
| 迟到响应 | 审核 A 后切换 B | A AuditRun 可保留，但不能成为 B 的 CURRENT 结果或高亮 |
| 生命周期 | 关闭重开 Popup、刷新、其他标签页 | 身份确认后才恢复；其他标签页不得继承结果 |
| 失败路径 | 不支持页面、API 不可用、401、403、CORS、tenant 不匹配 | 显示安全错误；不得放宽认证/CORS 或泄漏凭据 |

## 停止试用条件

发现旧岗位作为新岗位 CURRENT、跨 tenant 数据、Token 出现在页面/日志/反馈、自动审核或自动高亮、AuditRun 错误归属、大量无法提取、重大且无法人工识别的误报/漏报，或 API/数据库持续不稳定时，立即暂停并升级。
