# 试用人员操作指南

1. 打开一个获准试用的招聘岗位页面，在同一标签页打开扩展 Popup。
2. 点击“提取当前岗位”，检查岗位名称、描述及可选字段；必要时人工修正。
3. 点击“提交审核”。阅读 Decision、Risk Level、Finding 和证据定位；`REVIEW` 表示需要人工复核，不是法律结论。
4. 如需定位原文，手动点击“在页面高亮”；审核结论以 Popup 结果为准。使用“清除高亮”删除扩展添加的标记。

## 状态含义

- `CURRENT`：提取或审核结果当前与标签页、页面身份和 generation 相匹配；它不是永久有效状态。
- `STALE`：页面已变化、身份不匹配或无法安全确认；旧结果不会代表当前岗位，提交和高亮按钮应禁用。
- `UNAVAILABLE`：Semantic Classifier 或 Reflection 等可选能力未配置或不可用；这不等于 Production YAML Rule Engine 审核失败，也不等于审核通过。

同一标签页切换岗位、刷新后身份无法确认、Popup 提示页面已变化、提交/高亮按钮被禁用时，必须重新点击“提取当前岗位”。重新提取不会自动审核；再次审核必须由用户明确点击提交。所有 Rule Engine 结论仍需要人工判断；发现误报、漏报或证据无法定位时，按反馈模板上报。

不要尝试通过返回、复制旧结果或修改页面绕过 `STALE`。页面切换不会删除后端历史 AuditRun，但该历史结果不能用于新岗位。
