# Component Size Guide

| 组件 | sm | default | lg |
| --- | --- | --- | --- |
| Button / Input / Select | 32px | 40px | 44px |
| Card padding | 16px | 20px | 24px |
| Card radius | 10px | 12px | 16px |
| MetricCard | — | 132px | 156px |
| Status/Risk badge | 24px | — | — |

同一网格中的 `MetricCard` 必须使用同一 size。标题限两行，说明限三行；长标识使用等宽字体、截断或详情视图。业务组件不得覆盖上述尺寸 token。
