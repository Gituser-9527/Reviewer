# Beta 测试稳定性报告

## 根因

日报服务按请求中的 `reportDate` 统计当日已创建的反馈；原测试固定使用 `2026-06-26`，而测试反馈的 `createdAt` 使用实际运行日期。因此 `feedbackOpened` 正确为 0，测试却期望 1。

## 修复

测试仍断言同日报包含一条开放反馈，但 `reportDate` 改为测试执行当天。这与生产统计口径一致，没有重试、跳过或削弱断言。

## 验证

`apps/api/src/beta-program/routes.test.ts` 连续运行 10 次，10/10 通过。

## 生产影响

无运行时代码变更。日报统计继续以报告日期为边界；跨日反馈不会被误计入历史日报。
