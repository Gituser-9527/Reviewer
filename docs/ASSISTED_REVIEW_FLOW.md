# 辅助审核工作流

1. 审核员在自己的 Chrome 会话中打开岗位详情并点击扩展。
2. 扩展读取当前页标题与主要文本，按 Adapter 优先级生成字段预览、置信度、完整度和警告。
3. 审核员可修正字段；修正字段标记为 `USER_CORRECTION`。
4. 审核员点击“开始审核”后，后端保存脱敏采集记录并调用既有审核管线。
5. Side Panel 展示结论、Finding、Evidence 与修改建议；用户可开关仅用于呈现风险文本的页面高亮。
6. 审核员作最终人工判断，并可提交反馈或打开完整后台详情。

任何提取失败、权限缺失、字段不完整、服务端异常或证据不足均不得视为通过，应保留预览/错误并交由人工确认；后端审核按既有降级策略输出 `REVIEW`。
