# 产品官网与 API 文档门户

## 目的

公开站点为招聘平台、企业客户和技术团队提供产品介绍、受控试用申请与开发者接入入口；管理后台仍保留在既有工作台，不改变其 API 或权限流程。

## 访问入口

- `/landing`：公开产品官网，包含产品能力、工作方式、使用场景、安全说明、套餐占位和试用申请。
- `/api-docs`：公开开发者门户，包含 API Key 认证、核心接口、TypeScript 接入示例与 Sandbox 说明。
- `/`：既有审核工作台入口。

## 试用申请与隐私

前端向 `POST /api/trial-requests` 提交公司名称、联系人、工作邮箱及可选场景信息。该接口不要求租户鉴权，以支持外部访客申请试用。

服务端不会保存完整邮箱：仅保存经过 `redactSensitiveInfo` 处理的邮箱展示值和 `hashSensitiveValue` 生成的 SHA-256 哈希。接口响应也不回传邮箱或其他联系信息。当前使用进程内 MVP 存储；接入持久化仓库前必须保持相同的脱敏字段模型和保留期限策略。

## 国际化

官网和门户沿用现有 `LanguageProvider`，支持 `zh-CN` 与 `en-US`。语言选择写入浏览器本地存储，因此切换语言不会改变当前路径或丢失已输入的表单状态。

## 接入边界

- 文档示例使用 `/v1/*` 稳定外部集成接口；产品现有 API 适配层负责其鉴权与版本兼容。
- API Key 仅可在服务端保存和使用，不应嵌入浏览器代码、日志或文档截图。
- 产品结论是合规风险辅助，不构成法律意见或法律裁判。
